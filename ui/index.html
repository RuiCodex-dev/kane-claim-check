Claim Check

Every promise a page makes about its store listings, proved where the link actually leads. Judged by Kane CLI in a real browser, with a known-false control in every run.

Or : a local landing page whose store listing quietly disagrees with it.

  1. Read the page
  2. Kane confirms the page says it
  3. Follow each store link
  4. Kane judges claim and negation
  5. Ledger
